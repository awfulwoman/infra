# ViewSonic Projector RS-232 Commands

Reference for the RS-232 protocol `device-controller-projector.yaml` talks over UART, transcribed from the projector's service manual. `device-controller-projector.yaml` only implements power on/off and status polling via its own (independently reverse-engineered) comments; everything else below is unused but kept here as a reference for extending it.

## Interface

| Setting | Value |
|---|---|
| Baud Rate | 115200 bps (default) |
| Data Length | 8 bit |
| Parity Check | None |
| Stop Bit | 1 bit |
| Flow Control | None |

Matches the `uart:` block already configured in `device-controller-projector.yaml`.

### Pin assignment (DE-9)

| Pin | Description | Pin | Description |
|---|---|---|---|
| 1 | NC | 2 | RX |
| 3 | TX | 4 | NC |
| 5 | GND | 6 | NC |
| 7 | RTSZ | 8 | CTSZ |
| 9 | NC | | |

## Command table

All commands are byte sequences, MSB-first, e.g. `0x06 0x14 0x00 0x04 0x00 0x34 0x11 0x00 0x00 0x5D`.

### Power

| Status | Action | Command |
|---|---|---|
| Write | Turn on | `0x06 0x14 0x00 0x04 0x00 0x34 0x11 0x00 0x00 0x5D` |
| Write | Turn off | `0x06 0x14 0x00 0x04 0x00 0x34 0x11 0x01 0x00 0x5E` |
| Read | Power status (on/off) | `0x07 0x14 0x00 0x05 0x00 0x34 0x00 0x00 0x11 0x00 0x5E` |

## Note on the deployed config vs. this manual

`device-controller-projector.yaml`'s power on/off and status-read comments were reverse-engineered independently (before this manual was on hand) and don't byte-for-byte match the table above — e.g. its `turn_off_action` sends `...0x11 0x00 0x00 0x5E` where this manual's official "Turn off" is `...0x11 0x01 0x00 0x5E`. Since the deployed config is what's actually working against the real hardware, it hasn't been changed to match this reference - treat this file as documentation for extending the config (e.g. adding volume, lamp mode, or source-switching controls), not as ground truth to reconcile the existing power logic against.
