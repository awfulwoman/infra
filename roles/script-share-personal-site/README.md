# Script to share my personal site's repo

This Ansible role takes the self-hosted repo for the [personal site](https://awfulwoman.com) and edits it for public release. It removes content that is no longer for public sharing, and replaces it with demo content. It then pushes the edited and truncated repo, a very shallow clone, up to GitHub.

* Website: https://awfulwoman.com
* Github repo: https://github.com/awfulwoman/personal-site
