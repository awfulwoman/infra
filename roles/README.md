# Ansible - Custom Roles

These roles are specialised to my home network. I try to keep them isolated from each other, but this is not perfect. If you copy them into your own project, they can run well for you, but I cannot guarantee this.

I run these roles on Ubuntu, because I use Ubuntu everywhere.

This repository also uses first-party and third-party roles, [installed through the Ansible Galaxy system](../meta/).

## Ansible

Specialised roles to allow Ansible-related tasks to run on a host.

## Bootstrap

Bootstrap a host with common functionality.

## Client

These roles install client software that works with a dedicated server.

## Compositions

These are mostly container-based applications that the host OS does not offer. They tend to have a web interface.

## Hardware

Roles to support specific hardware configurations.

## Infra

Specialised roles that provide infrastructure that keeps all hosts running.

## Monitoring

Roles that monitor the health of a host.

## Network

Network-related roles.

## Server

These roles install server software that works with specialised clients.

## System

Generic system-level roles.

## User

If a host needs a specialised user account, one of these roles installs it.

## Virtual

Anything related to virtualisation, either at a host or guest level.
